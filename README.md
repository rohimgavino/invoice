# Invoice Generator - Oleh Oleh Jogja Hits

Aplikasi web generator invoice otomatis dan siap cetak/simpan PDF A4 untuk Oleh Oleh Jogja Hits.

## Fitur
- Input invoice real-time
- Format mata uang Rupiah otomatis
- Desain faktur profesional siap cetak / PDF (A4)
- Berjalan langsung di browser (client-side static web app)
